# 「シャッフルテキスト」プラグイン

> [!WARNING]
> このプラグインのymmeは公開していません。  
> のちに更新によって自動的に使用できるようになるかと思いますので、それまでお待ちください。

## 概要
テキストをシャッフルするエフェクトです。  

## 使い方
1. テキストアイテムを追加して、`アニメーション`カテゴリーにある「シャッフルテキスト」を選択して追加してください。
2. テキストの`文字ごとに分割`をオンにしてください。

## 効果
### 間隔
アニメーションテキストの変化する間隔を指定します。

### ずれ
テキストごとのアニメーションにずれを発生させます。

---

### 表示テキスト
|アルファベット|数値|記号|カスタム|
|-|-|-|-|
|アルファベット大文字・小文字|0~9|よく使われる記号([詳しくは](RandomText.cs#L76))|以下の通りです|

#### カスタム
- カスタム
  - A-Z
  - a-z
  - ひらがな
  - カタカナ
  - 漢字
  - 数字
  - 記号
- テキスト

### フォント・サイズ・文字色・太字・イタリック
基本機能と同じです。
